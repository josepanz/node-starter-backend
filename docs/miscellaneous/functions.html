src/core/scheduler/with-advisory-lock.ts

withAdvisoryLock
withAdvisoryLock(prisma: Pick, lockId: number, fn, options: IAdvisoryLockOptions)

Patrón: exclusión mutua entre réplicas con advisory lock de Postgres (sin Redis ni infra extra). Se toma pg_try_advisory_xact_lock dentro de una transacción interactiva: el lock queda atado a ESA conexión y se libera solo al terminar la transacción (commit, rollback o timeout). Un pg_try_advisory_lock de sesión sobre un pool de conexiones puede tomarse en una conexión y "liberarse" en otra, dejando el lock huérfano; la variante transaccional elimina ese riesgo. fn corre con el cliente normal (otra conexión del pool), por eso el pool necesita >= 2. Si otra réplica ya tiene el lock devuelve { acquired: false } sin esperar.
